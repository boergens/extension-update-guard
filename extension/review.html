History

    Update Guard acts after Chrome has installed an update, so a new version can run for a moment before it is turned off. Chrome does not let one extension read another's code: to read it yourself, look in the Extensions/<ID> folder inside your profile folder (the "Profile Path" on chrome://version). After an update the old and the new version sit there side by side until Chrome restarts, so that is the time to compare them.
